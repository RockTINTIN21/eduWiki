## Описание проекта

**EduWiki** — это платформа, где пользователи могут:

* Просматривать информацию о странах, университетах и образовательных программах.
* Добавлять и редактировать контент, созданный другими участниками.
* Создавать подробные описания университетов и программ обучения за границей.

Проект направлен на облегчение доступа к актуальной информации об образовании за рубежом для студентов и школьников СНГ.

---

## Стек технологий

### Backend

* **Nest.js** — серверная часть
* **Prisma ORM** — работа с базой данных
* **PostgreSQL** — реляционная база данных

### Frontend

* **Next.js** — фреймворк для React
* **React Hook Form** — управление формами
* **Redux Toolkit (RTK)** — управление состоянием

---

## Минимальные требования

* **Node.js** версии 18.0.0 или выше (рекомендуется LTS, например 18.18.0)
* **PostgreSQL** сервер
* **npm** версии 7.0.0 или выше

Установка зависимостей:

```bash
npm install
```

## Как запустить проект

### Backend

```bash
cd backend
npm run start:dev
```

### Frontend

```bash
cd client
npm run dev
```

Откройте [http://localhost:3001](http://localhost:3001) для просмотра.
