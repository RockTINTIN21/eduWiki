# EduWiki Frontend

## Стек технологий

* **Next.js** — фреймворк для React
* **React Hook Form** — управление формами
* **Redux Toolkit (RTK)** — управление состоянием

## Установка и запуск

1. Установить зависимости:

```bash
npm install
```

2. Запустить проект:

```bash
npm run dev
```

3. Открыть в браузере [http://localhost:3001](http://localhost:3001)
